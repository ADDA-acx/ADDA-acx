### 01 / ABOUT · 关于我

我目前在韩国全南国立大学攻读融合生物系统机械工程硕博连读项目，并辅修 **IT–Bio 融合系统**方向。研究聚焦农业移动机器人的自主导航、任务规划、路径生成，以及基于优化的轨迹跟踪控制。

我的工作围绕一个具体的问题展开：**机器人如何在果园、丘陵与农田等真实户外环境中，自主而可靠地完成任务？**

> 从平台硬件、传感器集成与地图构建，到全局规划、局部轨迹优化和闭环控制——记录推导，也记录那些让机器人真正跑起来的细节。

### 02 / RESEARCH · 研究主线

| 方向 | 关注内容 |
| --- | --- |
| **Autonomous Navigation** | 面向果园与农田环境的定位、建图、任务规划与自主作业 |
| **Trajectory Optimization** | Hybrid A*、B-spline、Minimum-jerk 与约束轨迹生成 |
| **Optimal Control** | NMPC、LMPC、CLF–CBF 与移动机器人轨迹跟踪 |
| **System Integration** | ROS、RTK-GNSS、3D LiDAR、IMU 与嵌入式平台集成 |
